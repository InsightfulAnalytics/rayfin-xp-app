# Wallpaper

`bliss.jpg` is the Windows XP "Bliss" desktop background, resized/compressed
for web use. The original photograph is owned by Microsoft (photographed by
Charles O'Rear). It is included here only as a decorative homage for this
Windows XP themed app, supplied by the project owner. Not public domain —
replace it if you reuse this project beyond personal/homage use.
